## 1. Product Overview

AlgoChat is a web application designed to help users chat in real-time with text, images, and voice notes — all in one place.

## 2. Problem Statement

People switch between multiple apps to share text, images, and voice messages. Existing tools are heavy, cluttered, and lack a clean, distraction-free chat experience with instant delivery feedback.

## 3. Goals

- Provide a simple, fast platform for real-time one-to-one messaging.
- Support rich messages: text, images, and voice notes with duration.
- Offer message status (sent → delivered → read) so users trust delivery.
- Offer a clean, modern, and distraction-free user experience.

## 4. Target Users

- Friends, teams, and communities needing quick real-time chats.
- Age group: 16–45
- Tech-savvy; uses laptops and smartphones
- Needs a simple, reliable tool for daily communication

## 5. Core Features (MVP)

1. **User Authentication** (Sign up / Login)
2. **Chat Dashboard** (user list, online status, selected chat)
3. **Messages** (Create, read, send text/image/voice)
4. **Media Gallery** (all shared images & voice notes)
5. **Message Status** (sent, delivered, read ticks)
6. **Profile Management** (full name, avatar upload)

## 6. Out of Scope (for MVP)

- Group chats
- Video calls
- Message editing/deletion
- End-to-end encryption
- Push notifications

## 7. Success Metrics

- Users can sign up and send a first message within 2 minutes.
- Message delivery latency under 1 second on a stable connection.
- 90%+ of messages reach `read` status when both users are online.
- Zero critical auth bugs at launch.

## 8. Future Enhancements

- Group chats and channels
- Typing indicators and read receipts per message
- Message reactions and replies
- Mobile apps (React Native)
- E2E encryption
